# Sparkfun Moisture Sensor

The SparkFun Soil Moisture Sensor measures the volumetric water content in soil.

It helps determine how wet or dry the soil is, making it useful for automated plant watering systems, greenhouse monitoring, and IoT agriculture projects. 

It works as a variable resistor: the resistance changes depending on soil moisture.
